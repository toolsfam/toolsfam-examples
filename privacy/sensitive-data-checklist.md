# Sensitive Data Checklist

Before using any online tool, check whether your input includes sensitive data.

## Be careful with

- API keys
- Passwords
- JWT tokens
- Bank statements
- Invoices
- Customer CSV exports
- Private PDFs
- Internal API responses
- Personal photos
- Source code from private projects

## Safer workflow

1. Remove secrets.
2. Use fake sample data.
3. Prefer local-first tools where possible.
4. Avoid uploading private documents unnecessarily.
5. Read the tool privacy note.
6. Copy only the final result you need.
